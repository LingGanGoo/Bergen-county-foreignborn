# Bergen County Foreign-Born Population Data, 1970–2020

This repository contains CSV datasets used to study foreign-born population trends in Bergen County, New Jersey.

The files include continent, subregion, country-of-birth, countywide, and municipality-level datasets derived from U.S. Census Bureau decennial census and American Community Survey products. The bibliography CSV records the principal sources used in the datasets.

Important methodological notes and coverage limitations are retained in the CSV provenance fields. Values labeled foreign stock are not interchangeable with foreign-born population estimates.
